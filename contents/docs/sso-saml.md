## Overview

**P2 — Enterprise:** SAML 2.0 and OIDC SSO for team workspaces, with enforced
domain verification and SCIM provisioning on the roadmap.

## Target capabilities

| Feature | Status |
| --- | --- |
| Google OAuth (individual) | Available today |
| SAML 2.0 (Okta, Azure AD) | Planned |
| Domain-restricted sign-in | Planned |
| SCIM user provisioning | Planned |

## Interim

Teams can invite members via email from **Dashboard → Settings**. See
[Access control](/docs/access-control) for project visibility rules.

For SSO pilots (YC / enterprise), reach out through [Contact](/contact).
