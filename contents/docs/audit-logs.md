## Overview

**P2 — Enterprise:** Immutable audit logs for compliance teams — who converted
which docs, when MCP tokens were used, and admin changes to domains or billing.

## Events (planned)

- Project created / re-synced / deleted
- MCP token minted / revoked
- Team invite accepted
- Domain or marketplace publish changes
- Admin user disable / subscription updates

## Today

- **MCP hits** are tracked per project on the dashboard (developer vs company).
- **Observability** metrics are available to doc2mcp operators in admin tooling.

Export APIs and SIEM webhooks are on the enterprise roadmap. Contact us for early
access.
